# 贪吃蛇

一个用纯 HTML + JavaScript（Canvas）编写的贪吃蛇游戏，不依赖任何第三方库，单文件即可运行。

## 运行方式

直接用浏览器打开 `index.html` 即可。

也可以启动一个本地服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 玩法

- 控制蛇吃掉 **红色食物**，每吃一个蛇身变长并得分（10 × 当前等级）
- 偶尔会出现 **金色食物**，限时存在，吃到额外加分（50 × 当前等级），快消失时会闪烁
- 每吃 5 个食物升一级，速度加快
- 撞到墙壁（有墙模式）或撞到自己，游戏结束
- 最高分会保存在浏览器本地

## 游戏模式

- **有墙模式**：碰到边界即失败
- **穿墙模式**：从一侧出去会从另一侧进来

## 操作

| 操作 | 键盘 | 手机 |
|---|---|---|
| 移动 | 方向键 / WASD | 在棋盘上滑动，或点击屏幕方向键 |
| 暂停 / 继续 | 空格 | 切到后台自动暂停 |
| 开始 / 重开 | 回车 | 点击按钮 |
